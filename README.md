# Breakroom Bot

Bored in the breakroom? Try out Breakroom bot!

## Commands

`/breakroom-ping`: Check server latency!
`/breakroom-decide`: Have a question? If you ask Breakroom it'll tell you if it's worth doing or not.
`/breakroom-joke`: Get a random joke.

## Editing

```bash
npm install
```

```bash
node index.js
```
